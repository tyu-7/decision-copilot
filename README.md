# Decision Copilot

> 不替你选，但帮你把下一步看清。

Decision Copilot 是一个面向毕业去向与早期职业选择的 AI 决策整理工具。当用户需要在两条不能充分并行的发展路径之间开始验证、准备或行动时，它帮助用户整理分散材料、个人底线和关键未知，形成可核对、可修改的决策依据与下一步行动。

当前版本为持续迭代中的 **P0 Web MVP**。

## 为什么做这个产品

前期研究覆盖了 **7 位独立参与者、8 个真实决策案例**。参与者普遍会从官网、社交媒体、熟人和通用 AI 获取大量信息，但这些信息并不会自然转化为更清楚的判断。

研究发现：

- 用户通常不缺观点，缺的是判断信息是否适用于自己；
- 事实、个人经验、未来预测和他人价值判断主要仍在头脑中混合整理；
- 用户常通过底线、排除、关键门槛和低成本行动收敛，而不是依赖完整的权重与总分；
- 形成偏好、正式行动和心理接受可能发生在不同时间。

因此，产品从早期的“权重＋评分＋AI 推荐”转向“证据整理＋底线识别＋未知管理＋行动准备”。

## 核心产品取舍

1. **AI 草稿不是事实**：模型负责理解和整理，但所有关键内容都需要用户确认。
2. **底线优先于偏好**：不能接受或必须满足的条件不会被其他优势抵消。
3. **证据不足是合法结果**：系统可以指出最值得验证的未知，而不是勉强给出推荐。
4. **最终选择属于用户**：产品对称呈现两条路径，不输出总分、排名或胜出者。

## 当前 Demo 能做什么

- 用自然语言描述两条现实路径，并确认系统理解；
- 整理已有材料，或在材料不足时规划验证方向；
- 在统一因素单元中维护 A/B 依据、底线和关键未知；
- 查看不替用户选边的决策准备摘要；
- 保存当前立场和一项具体的下一步行动；
- 在 AI 不可用时使用相同结构手动完成流程；
- 在浏览器本地保存和恢复当前决策。

## 技术概览

项目使用 React 19、TypeScript、Vinext 与 Vite 构建，部署于 OpenAI Sites / Cloudflare Workers；Cloudflare D1 用于任务幂等、授权限速与预算计数，DeepSeek Responses API 提供可选 AI 辅助。用户的决策正文和工作区快照默认保存在浏览器本地。
